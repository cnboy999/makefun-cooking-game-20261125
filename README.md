**Sizzle & Serve: Wok Rush** — a fast-paced cooking game. Chop it, fry it, plate it, beat the clock: take orders from the board, chop ingredients on the cutting board, grill patties and boil pasta on the stove, mix dishes in the pan, and serve each ticket before its patience runs out. A 3-minute shift, combos for fast serves, and three hearts of reputation to lose. All art is drawn in code and all sounds are synthesised — no assets, no network, it plays offline in a desktop browser from its own files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static server. `node main.ts` (with `MAKEFUN_OUTPUT_DIR` set) hands the game in for the make.fun grader.
